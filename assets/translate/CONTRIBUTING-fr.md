# Contribuer à ce projet

Si vous êtes arrivé jusqu'ici, vous êtes prêt à contribuer.

## Pré-requis

Assurez-vous d'avoir une bonne expérience avec JavaScript. Si vous avez déjà créé ou contribué à un projet similaire, c'est un atout.

## Suivez ces étapes

Avant même de **[forker](https://github.com/daoodaba975/galsenify/fork)** le projet, veuillez d'abord créer une **[issue](https://github.com/daoodaba975/galsenify/issues/new)** pour expliquer ce que vous prévoyez de faire dans votre contribution.  
Je serai très attentif, et nous pourrons en discuter.
